## How To Use This In A Real Project

**Purpose:** ayudar a nuevos lectores a navegar fuentes de verdad sin perder contexto.

**What belongs here:** rutas recomendadas por rol, convenciones de nombres y explicacion de fuentes autoritativas.

**What does NOT belong here:** copiar contenido completo de cada documento.

**Owner / reviewers:** Solution Architect y Tech Lead.

**When required:** `REQUIRED` cuando el manifest tenga mas de unos pocos artefactos.

**Common mistakes:** asumir que el README basta; dejar contratos sin enlaces desde decisiones.

**Implementation handoff:** un developer o agente de IA debe poder encontrar rapido el artefacto autoritativo.
