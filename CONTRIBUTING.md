# Contributing

Este repositorio es un ejemplo educativo. Mantenerlo util exige coherencia entre narrativa, contratos y validaciones.

## Rules

- Mantener todo el contenido publico, ficticio y neutral.
- Usar `Acme Retail` como organizacion ficticia.
- Escribir documentacion principal en espanol.
- Mantener nombres tecnicos en ingles cuando ayuden a convenciones de ingenieria.
- No duplicar contratos machine-readable en Markdown.
- Agregar o actualizar ADRs cuando cambie una decision significativa.
- Ejecutar `npm run validate` antes de proponer cambios.

## Definition Of Review

Un cambio debe responder:

- Que decision o contrato cambia.
- Que artefactos relacionados fueron actualizados.
- Que validaciones pasan.
- Que riesgos u open questions quedan visibles.
